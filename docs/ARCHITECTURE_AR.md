# البنية التقنية لتطبيق جدولي

> مراجعة ثابتة للكود المصدري المرفق، دون إعادة تشغيل الاختبارات أثناء إعداد الوثيقة.

## تصور طبقات التطبيق

```text
┌───────────────────────────┐
│ Screens / Material 3 UI   │  الجدول، التقويم، الإحصائيات، الصلوات
└────────────┬──────────────┘
             │ متابعة الحالة والاستدعاءات
┌────────────▼──────────────┐
│ Provider / ChangeNotifier │  TaskProvider / PrayerProvider / ThemeProvider
└──────────┬────────┬───────┘
           │        │
┌──────────▼────┐ ┌─▼───────────────────────┐
│ SQLite /      │ │ NotificationService     │
│ DatabaseHelper│ │ Local Notifications     │
└───────────────┘ └─────────────────────────┘
```

## وحدات المشروع المهمة

| الملف | مسؤوليته في المشروع |
| --- | --- |
| `lib/main.dart` | تهيئة اللغة العربية و`MultiProvider` والإشعارات والسمة |
| `lib/models/task_model.dart` | نموذج المهمة والحالة والأولوية والتواريخ وخيارات الظهور والتنبيه |
| `lib/models/prayer_model.dart` | نموذج الصلاة وحالة الأداء وعدد الركعات |
| `lib/providers/task_provider.dart` | قراءة المهام حسب التاريخ، إنشاء روتين يومي، التعليم بالإنجاز، التأجيل والتعديل والإخفاء والتنبيهات |
| `lib/providers/prayer_provider.dart` | تسجيل الصلوات، تغيير اليوم، إعداد إحصائيات الجماعة |
| `lib/providers/theme_provider.dart` | تفضيلات الألوان والوضع الداكن |
| `lib/database/database_helper.dart` | إنشاء قاعدة البيانات والجداول وعمليات CRUD وترقيات النسخ |
| `lib/services/notification_service.dart` | إعداد الإشعارات وحجزها وإلغاؤها |
| `lib/screens/` | الشاشات التفاعلية ومسارات التنقل |

## تدفق إضافة مهمة

1. يُدخل المستخدم العنوان، وقتي البداية والنهاية، والأولوية في شاشة الجدول.
2. تتحقق واجهة الإدخال من القيم قبل الحفظ.
3. ينفّذ `TaskProvider` حفظ المهمة عبر `DatabaseHelper` وSQLite.
4. يحاول `NotificationService` جدولة تذكير مستقبلي إذا كانت الأذونات والظروف تسمح.
5. يعيد المزود تحميل قائمة اليوم ويُخطر الواجهة بالتغييرات.

## التخزين دون اتصال

البيانات الأساسية محفوظة في قاعدة SQLite باسم `smart_daily_planner.db`. يحتوي المخطط الحالي على جدول للمهام وجدول للصلوات. الإصدار المسجل لقاعدة البيانات هو **3**، وتتضمن عمليات الترقية إضافة إعداد كتم تذكير المهمة وجدول الصلوات للإصدارات الأقدم.

**ملاحظة:** يعتمد رابط التواصل في شاشة «عن التطبيق» على فتح خدمة واتساب خارج التطبيق، وهو ليس جزءًا من الوظائف المحلية الأساسية.

## إدارة التاريخ والإشعارات

- تاريخ المهمة محفوظ بصيغة `YYYY-MM-DD`، ووقت البداية/النهاية بصيغة `HH:mm`.
- يوجد منطق لتحديد المهام المتأخرة عند تحميل قائمة اليوم.
- تُدرج مهام افتراضية لبعض الأنشطة والصلوات بأوقات ثابتة؛ ليست أوقات صلاة ديناميكية محسوبة بحسب الموقع.
- تستخدم الإشعارات المجدولة واجهة `flutter_local_notifications`، وقد تتأثر بأذونات Android أو إعدادات الطاقة.

## الاختبارات الموجودة في المشروع
